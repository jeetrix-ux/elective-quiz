# Elective Compass

A quiz for choosing **Professional Elective II and III** (NIT Warangal B.Tech ECE, 6th semester, 2024-25 curriculum).

**Live:** https://jeetrix-ux.github.io/elective-quiz/

- **Part 1 · About you:** prerequisites (EC1321), target hardware roles, GATE, honors, maths/coding comfort, exam style, workload.
- **Part 2 · Scenarios:** 14 situational picks.
- **Part 3 · Blind syllabus taste test:** 49 real syllabus topics, shuffled, with course names hidden.
- **Part 4 · Readiness check:** 16 foundation questions (2 per course).

Results: the best PE-II + PE-III pair, the exact preference order for the form, a per-course breakdown (interest, fit, readiness, grade outlook, hardware-job value), pair synergy, and a hardware-job lens.

Difficulty, grading and job-value numbers are estimates from the syllabi and 2025-26 hiring reports, not official grade data. See the **Method** tab.

Plain HTML/CSS/JS with no build step. Answers are saved in `localStorage`.
